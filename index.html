How it works

Four steps from class name to styled element

01

import

Import the utility map from cssobjects.js into your runtime.

02

scan

The engine scans all DOM nodes for class names starting with masala-.

03

lookup

Each class is looked up in the map and its CSS declaration is fetched.

04

apply

Declarations are appended to the element's inline style. Done.
