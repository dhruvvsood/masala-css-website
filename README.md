# MasalaCSS — Utility-first CSS, desi style

A modern utility-first CSS framework with a distinctive desi (Indian) aesthetic. MasalaCSS provides a comprehensive set of utility classes to rapidly build responsive and beautiful web interfaces.

## Features

- **Utility-first approach**: Compose styles directly in your HTML using pre-defined utility classes
- **Desi style theme**: Culturally inspired design with beautiful typography and colors
- **Dark/Light mode support**: Built-in theme toggle for optimal viewing experience
- **Responsive design**: Mobile-first approach with responsive utilities
- **Lightweight**: Minimal dependencies with Vite for fast development and builds

## Project Structure

```
masala-css-website/
```

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/DhruvSood05/masala-css.git
cd masala-css-website
```

2. Install dependencies:

```bash
npm install
```

### Development

Start the development server with hot module reloading:

```bash
npm run dev
```

The site will be available at `http://localhost:5173` (or your configured Vite port).

### Production Build

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Available Utilities

MasalaCSS includes utility classes across multiple categories:

### Colors

- Background colors: `masala-bg-red`, `masala-bg-blue`, `masala-bg-green`, `masala-bg-black`, `masala-bg-white`
- Text colors: `masala-text-red`, `masala-text-blue`, `masala-text-black`, `masala-text-white`

### Typography

- Font sizes: `masala-text-sm`, `masala-text-md`, `masala-text-lg`, `masala-text-xl`
- Font weights: `masala-font-bold`, `masala-font-normal`

## Theme Toggle

The website includes a built-in theme toggle that switches between light and dark modes. Users can toggle the theme using the button in the navigation bar.
